Meteora DBC is Meteora's permissionless token launch infrastructure. Define how a token launches, trades, and graduates into Meteora liquidity, all through a configurable on-chain bonding curve.

- [Get Started with Meteora DBC](https://docs.meteora.ag/developer-guides/dbc)
- [Invent CLI](https://docs.meteora.ag/invent/actions)
- [Next.js Scaffold Template (Fun Launch)](https://docs.meteora.ag/invent/scaffold/fun-launch)
- [TypeScript SDK](https://docs.meteora.ag/developer-guides/dbc/typescript-sdk/getting-started)
- [NPM Package](https://www.npmjs.com/package/@meteora-ag/dynamic-bonding-curve-sdk)
- [Agent Skill](https://docs.meteora.ag/agents/skill)

We believe there is a lot left to tokenize, so we need more innovative launchpads. Meteora lets you build a launchpad that does stock pairs, ICM pairs, meme pairs, and fully custom pair setups: more asset classes on the same liquidity layer.

For liquidity-related integrations, check out the [Meteora docs](https://docs.meteora.ag/get-started).
